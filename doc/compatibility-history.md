# Recovered Coffee GB compatibility reports

Reconstructed on **2026-09-30**: **176 game/demo/cartridge entries from 172 historical issue numbers**. This preserves the reported symptoms and the changes associated with them. It is a historical regression checklist, not a new test of every game on current Coffee GB.

The recovery uses local **Codex and Claude chat archives on gallifrey**, repository commit history, surviving pull requests, and the [16 July 2026 Wayback issue index](https://web.archive.org/web/20260716225533/https://github.com/trekawek/coffee-gb/issues). That snapshot independently preserves 12 report titles, numbers, and ScottNash042 attribution. Claude records recovered seven additional issue titles absent from the structured Codex recovery: #43, #44, #45, #47, #49, #51, and #55.

The [machine-readable catalog](compatibility-history.json) retains original report titles (including region/revision and trainer annotations), captured reporter attribution, full commit IDs, PR links, and precise local transcript/session references. Most entries are ScottNash042 reports; related follow-up reports are retained, and missing author fields remain explicitly unknown. No ROM/save contents, ROM checksums, or full private chat transcripts are included.

**Reading the outcomes:** “Historical fix” means the recovered investigation attributes the symptom to a change present in the local `master` history. “Partial” and “Disputed / unresolved” must not be read as fixed. “Not reproduced” is an investigation result, not proof that the original report was false. “Hardware behavior” requires a recovered hardware confirmation. A setup/progression outcome has no newly attributed emulator fix. Empty commit cells are intentional.

Fix links use commits reachable from local `master` at `3c92d624`; the current remote head was also checked at `5158400f` and differs only by a Kudos documentation change. Rebased PR commits were matched to landed commits; where a PR was folded into another change, the landed commit is used. Early fixes can be superseded by later implementations. Historical issue links retain identity but may return 404 after deletion.

## Cases requiring care

- **Yu-Gi-Oh! Early Days Collection (#658):** a patch merged, but the reporter subsequently said the card art remained wrong. It is disputed, not conclusively fixed.
- **Renju Club (#688):** a fresh investigation following [the surviving report #692](https://github.com/trekawek/coffee-gb/issues/692) confirms link-cable support and retracts the old hot-seat-only conclusion. The game's initial role election can expire before netplay attaches; resetting one connected machine establishes link roles. See the [startup investigation and boot-policy fix](renju-club-link.md). #690 remains a general SGB netplay setup change, not a Renju-specific fix.
- **Master Karateka (#665), Kanjiro (#174), and Xin Shuma Baobei Huang (#258):** recovered fixes cover only part of the reported behavior or hardware modes.
- **Bomber Man audio, MainBlow, NBA Jam 99, and F-1 Race:** early diagnoses or first patches were corrected later. The entries below reflect the later evidence.
- **Five DMG link fixes (#580, #581, #586, #587, #588):** initial game-specific patches were superseded by the shared scheduler correction in #617. Both stages are retained.

## Coverage and limits

The table keeps separate reports for separate symptoms in the same game. Multicart families and paired releases remain grouped where the original report grouped them; #32 is split into its five named games. Names are shortened for readability, while the JSON preserves the captured title. Demos, trainers, pirate translations, utilities, and unusual cartridge hardware are retained because their emulation requirements differ from the retail games.

General UI requests, release tasks, test-suite uploads, and unnamed peripheral feature requests are outside this game-focused table. Relevant recovered non-game records include Sachen mapper support (#58), rumble (#93), Mobile Adapter (#311), GBKiss (#672), Turbo File (#676), and sewing machines (#677).
