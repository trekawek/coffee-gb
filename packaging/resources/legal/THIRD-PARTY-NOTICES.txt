Target-specific statically embedded OpenCV components
-----------------------------------------------------
Linux x86-64 embeds Intel IPP and IPP Integration Wrappers 2021.10.0. Its pinned OpenCV download is
ippicv_2021.10.0_lnx_intel64_20230919_general.tgz (MD5
606a19b207ebedfe42d59fd916cc4850) at OpenCV third-party commit
0cc4aa06bf2bef4b05d237c69a5a96b9cd0cb85a. See
licenses/Intel-IPP-EULA-October-2022.txt and
licenses/Intel-IPP-2021.10.0-third-party-programs.txt.

Windows x86-64 embeds Intel IPP and IPP Integration Wrappers 2021.11.0 according to the binary's
own build information. It was taken from the official opencv-4.9.0-windows.exe, SHA-256
fefddff0623fbd5a6fa0cecb9bccd4b822478354e6c587ebb6e40ab09dacba51. The official installer's
accompanying third-party-program file identifies "Intel(R) Integrated Performance Primitives
2021 Update 10", while the packaged binary identifies 2021.11.0. The official file is preserved
verbatim in licenses/Intel-IPP-Windows-4.9.0-third-party-programs.txt rather than silently
rewritten. The governing EULA is licenses/Intel-IPP-EULA-October-2022.txt.

Linux and Windows also embed the Khronos OpenCL 1.2 headers under the MIT license. See
licenses/OpenCV-OpenCL-Headers-LICENSE.txt. Windows additionally embeds ADE 0.1.2d under
Apache-2.0 (licenses/Apache-2.0.txt) and Intel vaSOT from the pinned OpenCV revision under MIT
(licenses/OpenCV-vaSOT-MIT.txt).

macOS x86-64 embeds Intel IPP and IPP Integration Wrappers 2021.9.1. Its pinned OpenCV download is
ippicv_2021.9.1_mac_intel64_20230919_general.tgz (MD5
14f01c5a4780bfae9dde9b0aaf5e56fc) at the same OpenCV third-party commit. See
licenses/Intel-IPP-EULA-October-2022.txt and
licenses/Intel-IPP-2021.9.1-third-party-programs.txt. It links the system OpenCL framework rather
than embedding the vendored headers.

macOS arm64 does not embed IPP. It embeds NVIDIA Carotene 0.0.1 and the OpenCV Tegra HAL under
BSD-3-Clause; Carotene's FAST implementation also carries Edward Rosten's BSD-3-Clause notice.
See licenses/OpenCV-NVIDIA-Carotene-BSD-3-Clause.txt,
licenses/OpenCV-NVIDIA-Tegra-HAL-BSD-3-Clause.txt, and
licenses/OpenCV-Carotene-FAST-BSD-3-Clause.txt.

The Windows OpenCV build metadata reports video I/O through FFmpeg, but the packaged OpenCV DLL
does not import an FFmpeg DLL and Coffee GB does not stage the separate
opencv_videoio_ffmpeg490_64.dll shipped by the official installer. That wrapper and its FFmpeg
payload therefore are not distributed in a Coffee GB target-native package and are not represented
as embedded components.

libsdl4j 2.28.4-1.6 / SDL 2.28.4
--------------------------------
Native source: https://github.com/libsdl-org/SDL/tree/release-2.28.4
Java binding source: https://github.com/libsdl4j/libsdl4j
License: zlib. See licenses/SDL2-zlib.txt.

The selected libsdl4j artifact contains audited SDL2 binaries for Linux x86-64 and Windows
x86-64. It contains no macOS SDL2 binary; macOS packages therefore use keyboard input unless the
user separately installs a compatible system SDL2 library.
