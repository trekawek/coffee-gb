ByteBounce bitmap atlas provenance
==================================

The packaged byte-bounce-small-atlas.png, byte-bounce-notice-atlas.png,
byte-bounce-medium-atlas.png, byte-bounce-display-atlas.png, and
byte-bounce-semibold-atlas.png files were rasterized from the licensed
ByteBounce Medium TTF supplied by the Coffee GB project owner.

The supplied TTF is a build input only. It is intentionally neither committed
to this repository nor packaged in ui-portable; the dependency-free RGBA
atlases contain the portable compositor's fixed glyph alphabet instead.

The deterministic build recipe is tools/generate_bytebounce_atlases.py.
