# Protocol-v9 contract fixtures

These files are synthetic Coffee GB contract data for issue #346. They contain no ROM, save,
StateFile, token generated for real use, path, credential, server response, or third-party binary.

- `messages.tsv`, `fields.tsv`, `capabilities.tsv`, `limits.tsv`, `timeouts.tsv`, `errors.tsv`, and
  `transitions.tsv` are the machine-readable numeric registries for `docs/netplay-protocol-v9.md`.
- `invitation-vectors.tsv` uses the public fixture token encoding of bytes `00..0f`; it is labelled
  test-only and is not accepted or generated by production.
- `invitation-lifecycle-vectors.tsv` freezes the 60/600-second lifetime bounds, exact expiry,
  one-use, slot binding, stop invalidation, and eight-attempt rate-limit rollover with a fake clock.
- `auth-vectors.tsv` freezes the exact HMAC proof over synthetic token/nonces; expiry, one-use,
  wrong-slot, and rate-limit behavior use an injected fake clock in the reference test.
- `preface-vectors.tsv` freezes the four-byte v9 versus legacy/unknown decision before any
  incompatible header byte is parsed or any response is emitted.
- `aggregate-vectors.tsv` freezes checked queue/session reservation exact and boundary+1 outcomes
  without allocating any declared wire payload.
- `wire-vectors.tsv` commits exact complete or deliberately hostile frame bytes. SHA-256 is over
  each decoded `input_hex` byte sequence. Each row also records decisive read, bounded payload
  allocations, prohibited live mutation, generator, expected state, outcome, and provenance.
- `manifest.tsv` lists every other artifact in this directory and freezes its whole-file SHA-256,
  kind, provenance, and reproduction method. It deliberately does not hash itself.

The Kotlin contract tests are the reference generator/reproduction method and execute every wire
row both whole and one byte at a time. To update deliberately, edit the normative document and
registry in one review, derive the bytes with the helper's canonical frame builder, record the
candidate bytes/hash, and run:

```bash
mvn -B -pl controller -am \
  -Dtest='eu.rekawek.coffeegb.controller.network.v9.*' \
  -Dsurefire.failIfNoSpecifiedTests=false test
```

Normal tests never regenerate resources. A stable ID, byte, limit, timeout, or expected error
change requires an ADR and protocol/schema version review.
